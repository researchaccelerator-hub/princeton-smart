# Security Policy

## Supported Versions

Only the latest published [release](https://github.com/researchaccelerator-hub/princeton-smart/releases/latest) of Princeton SMART receives security updates. Older releases are not patched. If you're running an older version, please update to the latest release before reporting a vulnerability, to confirm the issue still applies.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use [GitHub Security Advisories](https://github.com/researchaccelerator-hub/princeton-smart/security/advisories/new) to report privately. This lets us discuss and fix the issue before it's publicly visible, and lets you track its status directly on GitHub.

When reporting, please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept
- The affected version/commit

We will acknowledge new reports and aim to keep you updated as we investigate. If the vulnerability is confirmed, we will work on a fix and coordinate a disclosure timeline with you. If it's declined (e.g. not reproducible, out of scope, or a duplicate), we'll explain why.
